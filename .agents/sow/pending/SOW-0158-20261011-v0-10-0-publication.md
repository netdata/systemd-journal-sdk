Sensitive data handling plan:

- Never record credentials. Record the CI run, package names, versions, tag
  object and peeled hashes and sanitized outcomes only. Raw reports stay under
  `.local/`.

Implementation plan:

1. Record the release PR merge SHA on canonical `master`; confirm tags absent.
2. After user authorization, dispatch the Release workflow with `0.10.0` and
   that SHA; save the successful run summary.
3. After the Release run succeeds, copy the version and source SHA from its
   summary and recheck local and canonical remote tags. A correct existing tag
   (annotated, peeling to the SHA) is preserved; a conflicting or lightweight
   tag stops the release for a user decision.
4. After user authorization, create only the missing annotated tags at the
   SHA. Push a new pair atomically to the canonical repository; if one correct
   sibling already exists, push only the missing tag (`RELEASING.md`).
5. Run `verify-go`; record results; complete this SOW.

Validation plan:

- `.agents/sow/audit.sh` complete-and-clean verdict.
